Strategy

Execution

Typical costs: US stocks 0–0.01% commission, crypto 0.04–0.1%.

Position size

Risk per trade sizes each position so that hitting the stop costs that % of your account. It needs a stop (from the strategy, ATR or %); position size becomes the most one trade may use.

Stops and targets

1R is the distance from entry to the stop. A strategy's own stop and target come first; then the ATR stop beats stop loss %, and reward:risk beats take profit %. Reward:risk and break-even need a stop.

Entry filters

Filters only block new entries; exits always go through. Trading hours use exchange time and apply to intraday data. Trend SMA: longs only above it, shorts only below. The daily loss limit closes the position and stops trading until the next day.

    Strategy API
    
          
    
            
    A strategy is one JavaScript file in strategies/:
    

    export default {
  name, description,
  params: { len: 20 },
  setup({ data, params, ta, plot }) {
    return { /* indicators */ };
  },
  onBar(ctx) { /* orders */ },
};
    
            
    params
    
            
    len: 20 or { value, min, max, step, label }. Booleans become checkboxes, { value: 'EMA', options: [...] } a dropdown.
    
            
    setup()
    
            
    Runs once. data.open/high/low/close/volume/time are arrays. Return the indicators you need; they arrive as ctx.ind.
    
            
    plot(name, series, { color, style, pane }) draws a line. style: line, dashed, dots, histogram. pane: 'lower' puts it under the price. Colours: vwap, band, accent, up, down or any CSS colour.
    
            
    onBar(ctx)
    
            
    Runs after each bar closes. ctx.i, ctx.close (and open, high, low, volume, time), ctx.ind, ctx.params, ctx.equity.
    
            
    Position: ctx.isFlat, ctx.isLong, ctx.isShort, ctx.position.entryPrice, .barsHeld, .pnlPct, .risk (1R in price).
    
            
    Session: ctx.newSession, ctx.lastBarOfSession, ctx.sessionBar, ctx.hour, ctx.minute, ctx.dayOfWeek.
    
            
    Orders
    
            
    ctx.long(opts), ctx.short(opts), ctx.exit(reason), ctx.cancel(), ctx.setStop(price), ctx.setTarget(price).
    
            
    opts: stop, target (prices), trail (%), size (0–1 of equity), label, atClose. Your own stop and target win over the sidebar's stop and target settings.
    
            
    Orders fill at the next bar's open. Stops and targets trigger inside the bar; a gap fills at the open.
    
            
    Helpers
    
            
    ctx.crossOver(a, b), ctx.crossUnder(a, b), ctx.prev(series, n), ctx.log(...).
    
            
    ta.sma ema wma rma stdev highest lowest rsi macd stoch roc change zscore bollinger donchian keltner atr trueRange adx obv hlc3 vwap vwapBands rollingVwap sessionStart sessionEnd sessionBar crossover crossunder
    
            
    Keep per-run state inside the object setup() returns, not in variables outside the strategy.
